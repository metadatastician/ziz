== Status — read this first

*Pre-alpha; milestone 0 runs.* This repository holds a design, a
tree-sitter grammar (corpus tests pass), and `ziz0`, a Chapel bootstrap
interpreter that compiles with Chapel 2.10 and runs every example in
`examples/` except the off-side `layout.ziz` (the `sexp` reader only, as
planned). `just test` checks all of that. If a model or a person tells you Žiz is "locked in", is
"dialectical", evaluates "triads", or can be "synthesised end-to-end in 48
hours", see link:TRIAGE.adoc[TRIAGE.adoc].

== Sixty-second tour

[source,lisp]
----
(define (fact n)
  (if (= n 0) 1 (* n (fact (- n 1)))))

(claim fact :arity 1 :evidence :asserted)   ; a judgement, with provenance
(print (fact 10))
----

----
$ ziz0 --file=examples/fact.ziz --jeg=observe
3628800
; --- JEG: 25 judgements, 206 evidence edges
(sym:fact :defined-at)  ; observed=1
(sym:fact :arity 1)  ; asserted=1 observed=11
(sym:fact :pure)  ; asserted=1
(sym:fact :callable)  ; observed=11
(sym:fact :takes 0 :int)  ; observed=11
(sym:fact :returns :int)  ; observed=11
...                     ; 19 more, about =, -, * and print
----

No type was declared. No type was checked. Every belief about `fact` is in
the graph with the evidence that supports it; tools decide what to do with
that, and they can disagree with each other.

== Building

Needs Chapel *2.10* (`just build` refuses any other `chpl`) and the
tree-sitter CLI.

----
just build           # chpl --fast bootstrap/ziz0.chpl -o ziz0
just examples        # run every examples/*.ziz the sexp reader can read
just examples-check  # ...and fail unless each prints its expected lines
just grammar         # tree-sitter generate && tree-sitter test
just ascii-check     # non-ASCII only inside strings and ; comments
just test            # grammar + examples-check + ascii-check
----

Chapel: the official release packages (github.com/chapel-lang/chapel,
release 2.10.0) install with the distribution's package manager. On the
estate's Debian 13 machine the `debian13` package is unpacked under
`tools/opt/chapel-2.10.0` instead, with a relocation wrapper on `PATH`; see
the README there. Its system dependencies are LLVM/clang 19 dev packages,
`libhwloc-dev` and `libunwind-dev`.

== Toolchain names

`claudia` · `boggs` · `federici` · `dunayevskaya` · `assata` — the owner's
names. Roles decided by the owner 2026-09-24: `claudia` = readers/printers,
`boggs` = evaluator, `federici` = JEG store, `dunayevskaya` = grammar/CST,
`assata` = CLI/REPL. See link:DESIGN.adoc[DESIGN.adoc] §Toolchain.

== Governance

Follows the Rhodium Standard Repository conventions from
`hyperpolymath/standards` (the RSR template supplies `SECURITY`,
`CONTRIBUTING`, `Mustfile`, `.machine_readable/`, etc.). Language policy:
Chapel for the bootstrap, C only for the tree-sitter scanner, JavaScript
only for the tree-sitter grammar DSL. No Python, no Rust component, no Deno.
