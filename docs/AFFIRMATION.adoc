== What this is, and how it works

Žiz is a pre-alpha language design: a unityped, homoiconic, reflexive language
with no typechecker, where a Judgement Evidence Graph records what is believed
about each term. The repo holds the design documents, a tree-sitter grammar
under `grammar/`, and `ziz0`, a bootstrap interpreter in Chapel
(`bootstrap/ziz0.chpl`). This file reports what the repo's own checks printed
against one commit on 2026-10-07. It supersedes the 2026-09-24 file, which was
an unfilled template and is now at
`docs/affirmations/AFFIRMATION-2026-09-24.adoc`.

=== The honest nuance you must not lose

* *The checks are expectation tests, not a specification.* `examples-check`
  requires 11 exact output lines from 5 programs. It shows that `ziz0`
  reproduces those lines, not that it implements `DESIGN.adoc`.
* *CI does not run these checks.* None of the 38 workflow files mentions
  `just test`, `examples-check`, `ziz0`, `chpl` or Chapel. Control: the same
  `grep -l` over them for `actions/checkout` matched 24 files. The evidence
  above is local only.
* *Environment matters.* With the machine's default shell environment,
  `just grammar` exited 1 with a mise "config not trusted" error raised from
  inside `tree-sitter generate`. The runs above used a clean environment
  (`env -i`, with `PATH` set to the Cargo and Chapel bins, and
  `TREE_SITTER_JS_RUNTIME=native`). The repo's `mise.toml` was not trusted
  and was not changed.
